# Create an Emission object for excess count detection

Create an Emission object for excess count detection

## Usage

``` r
Emission(distribution, excode_formula, initial_mu = NULL)
```

## Arguments

- distribution:

  excodeFamily object.

- excode_formula:

  excodeFormula object.

- initial_mu:

  Initial estimates of the mean for 'MultiState' models.

## Value

An
[`Emission`](https://robert-koch-institut.github.io/excode/reference/Emission-class.md)
object.
