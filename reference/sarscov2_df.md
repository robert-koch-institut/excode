# SARS-CoV-2 infections in Berlin-Neukölln (Germany)

A dataset containing the daily number of reported SARS-CoV-2 cases from
March-July 2020 in Berlin-Neukölln
<https://robert-koch-institut.github.io/SARS-CoV-2-Infektionen_in_Deutschland/>.
The dataset was downloaded on 2024-10-31. The variables are as follows:

## Usage

``` r
sarscov2_df
```

## Format

A data.frame with 154 rows and 3 variables:

- date:

  Day of data collection

- observed:

  Number of cases
